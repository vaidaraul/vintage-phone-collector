# Lumia 535 Microsoft News — synthetic test feed

This branch is a **schema test**, not a production news feed.

It contains three synthetic headlines and abstracts only. No real article
content is published here. The files are generated by the Lumia workspace tool
`tools/news-feed/generate.mjs --synthetic`.

The original Microsoft News app on the Lumia 535 is pointed at these URLs to test
which legacy envelope shape the old feed parser accepts:

- `stream.json` — stream document with `streamEntities`
- `experience.json` — older CMS experience/canvas/module shape
- `stream-elements.json` — stream document with `streamElements`
- `stream-cluster.json` — bare cluster array
- `stream-source.json` — source list with a nested stream document
- `source-metadata.json` — source metadata with feed items
- `categories.json`, `sources.js`, `partner.js`, `adsettings.json` — support files

Do not use this branch as the final feed. Once a shape renders on the phone, the
real generator publishes current article metadata to a separate feed branch.
